## Описание

Локальная поисковая система для индексирования и полнотекстового поиска по документам форматов **PDF, DOCX, TXT** с разграничением прав доступа на уровне ролей.

### Ключевые возможности

| Модуль             | Описание                                                                                                                                              |
|--------------------|-------------------------------------------------------------------------------------------------------------------------------------------------------|
| **Индексирование** | Многопоточное инкрементальное индексирование с прогресс-баром; проверка ACL перед индексированием; автоочистка удалённых файлов из индекса            |
| **Поиск**          | По ключевым словам (с лемматизацией и синонимами), по диапазону дат, по имени файла, комбинированный                                                  |
| **Безопасность**   | Ролевая модель (admin / user), PBKDF2-HMAC-SHA256 + salt, шифрование токенов Fernet (AES-128-CBC), защита от timing attacks, блокировка при брутфорсе |
| **ACL**            | Гибкие маски доступа (`D:\Docs\*`, `*.pdf`), рекурсивные и точные правила, кэширование правил                                                         |
| **GUI**            | Единое окно с тёмной темой (VS Code-like), панель администратора, предпросмотр с подсветкой совпадений, статус-бар                                    |

## Использование

### Индексирование (только admin)

1. Нажать **«Индексирование»** в верхней панели
2. Выбрать директорию с документами
3. Дождаться завершения (прогресс-бар + статус)

> Повторное индексирование пропускает неизменённые файлы (проверка по `mtime`).

### Поиск

| Режим | Как использовать                                                       |
|-------|------------------------------------------------------------------------|
| **Ключевые слова** | Ввести запрос, выбрать область (Только в содержимом), нажать **Поиск** |
| **По дате** | Включить чекбокс «Фильтровать по дате», выбрать диапазон               |
| **По имени файла** | Ввести имя или часть имени, выбрать область «Только в именах файлов»   |
| **Комбинированный** | Запрос + дата одновременно                                             |

### Предпросмотр

Нажать **👁** в строке результата — откроется окно с подсветкой совпавших терминов.

### Управление доступом (admin)

- **Пользователи** — создание, блокировка, назначение ролей
- **Доступ** — маски путей (`D:\Docs\*`, `*.pdf`), рекурсивные / точные правила

## Безопасность

| Механизм | Реализация |
|----------|------------|
| Хеширование паролей | PBKDF2-HMAC-SHA256, 100 000 итераций, случайная соль |
| Защита от timing attacks | `hmac.compare_digest()` |
| Брутфорс-защита | Блокировка на 30 сек после 5 неудачных попыток |
| Токены сессии | `secrets.token_urlsafe(32)`, TTL 1 день / 30 дней |
| Шифрование токенов | Fernet (AES-128-CBC), ключ в Credential Manager или файл `.token_key` (0o600) |
| Разграничение доступа | Проверка ACL при индексации, фильтрация результатов поиска по ролям |

## Технологии

- **Whoosh** — полнотекстовый поисковый движок
- **PyQt6** — GUI
- **SQLAlchemy + SQLite** — пользователи, сессии, ACL
- **PyMuPDF (fitz)** — извлечение текста из PDF
- **python-docx** — извлечение текста из DOCX
- **pymorphy3 + ru_synonyms** — лемматизация и синонимы (русский)
- **NLTK WordNet** — синонимы (английский)
- **cryptography** — шифрование токенов
